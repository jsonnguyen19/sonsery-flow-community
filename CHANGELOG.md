## [Unreleased]

### Added

- Community edition: MIT-licensed, open-source build of Sonsery Flow.
- Core automation flow: shell, read, replace, write tools.
- Bridge RPC read tools over a localhost HTTP bridge.
- AI adapters: ChatGPT, Claude, Gemini, DeepSeek, plus a generic fallback.
- Chrome/Edge MV3 extension with a side panel UI.
- Clipboard watcher + result watcher automation loop.
- Python test suite (pytest) and JavaScript e2e tests (Vitest).
- CI workflow: Ruff, BasedPyright, Pytest, ESLint, Prettier.
